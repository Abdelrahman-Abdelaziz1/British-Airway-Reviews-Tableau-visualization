# British Airways Customer Reviews Analysis & Visualization

## 📌 Project Overview
This project provides a comprehensive data analysis of British Airways customer reviews to identify key drivers of passenger satisfaction and service performance. By analyzing structured datasets, the project uncovers actionable insights into airline service quality, seat comfort, and overall travel experience across different countries.

## 📊 Dataset
The analysis is based on two primary datasets:
*  ba_reviews.csv : Contains raw customer feedback, star ratings, and review categories.
*  Countries.csv : Geographic data used to map satisfaction levels globally.

## 🛠 Tools Used
*  Tableau : For creating an interactive Business Intelligence dashboard.
*  Excel/CSV : For data structuring and initial exploration.

## 🚀 Key Insights & Features
*  Satisfaction Mapping : Visualized customer sentiment across different regions to identify high and low-performing markets.
*  Service Performance : Analyzed the correlation between specific service attributes (e.g., cabin staff, food & beverages) and the likelihood of a customer recommending the airline.
*  Experience Drivers : Identified key factors that lead to negative reviews to suggest targeted service improvements.

## 📂 Files in this Repository
* British Airways Reviews.twbx: The complete Tableau Packaged Workbook with interactive dashboards.
* ba_reviews.csv & Countries.csv: The underlying datasets used for the visualization.
